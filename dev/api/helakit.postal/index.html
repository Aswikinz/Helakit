    helakit.postal

    Sri Lankan postal-code validation.

    PostalBatchResult dataclass 

    PostalBatchResult(results: list[PostalResult], duplicates: dict[str, list[int]] = dict(), summary: PostalSummary = (lambda: PostalSummary(0, 0, 0, 0, 0, 0))(), df: Any | None = None)

    The outcome of validating a list / Series / DataFrame of postal codes.

    Behaves like a familiar pandas-style container: it has a length, iterates over its rows, supports integer and slice indexing, and converts to tabular form via :meth:to_pandas / :meth:to_polars / :meth:to_dicts regardless of what shape the input was.

    Attributes:

    Name Type Description
    results list[PostalResult]

    One :class:PostalResult per input row, in input order.
    duplicates dict[str, list[int]]

    Mapping from canonical code to the row indices it appeared at. Only entries with two or more indices are included.
    summary PostalSummary

    Roll-up counts. Also reachable via :meth:describe.
    df Any | None

    When the input was a pandas or polars DataFrame, this is a copy of that frame with helakit's per-row columns appended. None for list and Series input — use :meth:to_pandas or :meth:to_polars there.

    invalid property 

    invalid: list[PostalResult]

    Only the rows that failed validation (order preserved).

    is_valid property 

    is_valid: list[bool]

    Row-aligned boolean mask, like a boolean Series.

    Drops straight into pandas/polars filtering::

    df[batch.is_valid]                    # rows with valid codes
df[[not v for v in batch.is_valid]]   # the offenders

    valid property 

    valid: list[PostalResult]

    Only the rows that validated cleanly (order preserved).

    __bool__ 

    __bool__() -> bool

    True only when every row validated cleanly.

    __getitem__ 

    __getitem__(index: int) -> PostalResult

    __getitem__(index: slice) -> list[PostalResult]

    __getitem__(index: int | slice) -> PostalResult | list[PostalResult]

    Integer indexing returns one result; slices return a list.

    Example

    batch[0] # first PostalResult batch[:3] # first three, like df[:3]

    describe 

    describe() -> PostalSummary

    Aggregate counts, mirroring DataFrame.describe.

    Returns the same object as :attr:summary; call batch.describe().to_dict() for a plain dict.

    head 

    head(n: int = 5) -> list[PostalResult]

    First n results, mirroring DataFrame.head.

    to_dicts 

    to_dicts() -> list[dict[str, Any]]

    One flat record dict per row (polars-style to_dicts).

    Needs no optional dependencies. The keys are the postal_* diagnostic columns documented on :meth:to_pandas, plus postal holding the original input value.

    to_pandas 

    to_pandas() -> Any

    Return the batch as a pandas DataFrame.

    When the input was already a pandas DataFrame this returns :attr:df (the input copy with diagnostic columns appended). For every other input shape — list, list-of-dicts, Series, polars frame — a fresh frame is built with one row per input and the postal_* diagnostic columns.

    Raises:

    Type Description
    InvalidInputError

    If pandas is not installed. Install it with pip install helakit[pandas].

    to_polars 

    to_polars() -> Any

    Return the batch as a polars DataFrame.

    Mirrors :meth:to_pandas: returns :attr:df when the input was a polars DataFrame, otherwise builds a fresh frame from :meth:to_dicts.

    Raises:

    Type Description
    InvalidInputError

    If polars is not installed. Install it with pip install helakit[polars].

    Returned in PostalResult.data["decoded"] and accessible as PostalResult.decoded.

    Attributes:

    Name of the post office the code names, as published by the Department of Posts (e.g. "Nugegoda").

    validate_postal 

    validate_postal(data: str) -> PostalResult

    validate_postal(data: list[str] | list[dict[str, Any]] | tuple[str, ...], *, postal_col: str | None = ..., district_col: str | None = ..., errors: BatchErrorMode = ...) -> PostalBatchResult

    validate_postal(data: Any, *, postal_col: str | None = ..., district_col: str | None = ..., errors: BatchErrorMode = ...) -> PostalBatchResult

    validate_postal(data: Any, *, postal_col: str | None = None, district_col: str | None = None, errors: BatchErrorMode = 'raise') -> PostalResult | PostalBatchResult

    Validate one or many Sri Lankan postal codes.

    Parameters:

    Name Type Description Default
    data Any

    A single postal code string, a list[str], a list[dict], a pandas/polars Series, or a pandas/polars DataFrame. A Series is treated like a list of strings — postal_col and friends do not apply (a Series has no columns).

    		 required
    postal_col str | None

    Column name holding postal codes. Required for DataFrame and list-of-dicts input; not accepted for Series input.

    		 None
    district_col str | None

    Column name holding a district (short code or name, any letter case). When supplied each row is cross-checked and the per-row result records whether the district matched.

    		 None
    errors BatchErrorMode

    Batch-only. "raise" (default) propagates :class:~helakit.InvalidInputError if any cross-check district value is unparseable, matching strict pandas semantics. "coerce" records the failure as a per-row error instead, so a single malformed row no longer aborts the whole batch.

    		 'raise'

    Returns:

    Name Type Description
    A PostalResult | PostalBatchResult

    class:~helakit.postal.PostalResult for scalar input, or a
    PostalResult | PostalBatchResult

    class:~helakit.postal.PostalBatchResult for any iterable input.
    PostalResult | PostalBatchResult

    When valid, normalized holds the canonical five-digit string and
    PostalResult | PostalBatchResult

    these typed properties are populated:
    PostalResult | PostalBatchResult
    • post_office — post office the code names (e.g. "Nugegoda").
    PostalResult | PostalBatchResult
    • district / district_code — e.g. "Colombo" / "CMB".
    PostalResult | PostalBatchResult
    • province / province_code — e.g. "Western" / "WP".
    PostalResult | PostalBatchResult
    • sub_post — True for a sub post office.
    PostalResult | PostalBatchResult
    • decoded — a :class:~helakit.postal.PostalDecoded bundle.

    Raises:

    Type Description
    InvalidInputError

    For unsupported input types, an invalid errors value, or unparseable district values when errors="raise". Passing a non-string scalar is a programmer error, not bad data.
    Error codes
    • postal.invalid_characters — input contains something other than ASCII digits (separators and surrounding whitespace are stripped first).
    • postal.invalid_length — all digits, but not exactly five of them.
    • postal.unknown_code — five digits that are not in the Department of Posts directory.
    • postal.not_a_string — batch-only; the row's value was not a string.
    • postal.bad_district_input — batch-only, errors="coerce"; the cross-check district value could not be parsed.
    Example

    Basic validation::

    >>> result = validate_postal("10250")
>>> result.is_valid
True
>>> result.post_office
'Nugegoda'
>>> result.district
'Colombo'
>>> result.province
'Western'

    Formatting tolerance::

    >>> validate_postal("  10250 ").normalized
'10250'

    Handling invalid input::

    >>> result = validate_postal("99999")
>>> result.is_valid
False
>>> result.errors[0].code
'postal.unknown_code'

    A whole column::

    >>> batch = validate_postal(["10250", "80000", "99999"])
>>> batch.is_valid
[True, True, False]
>>> batch.describe().valid
